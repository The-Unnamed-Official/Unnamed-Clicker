# Button Clicker

A progression-based clicker game where clicking buttons unlocks increasingly powerful upgrades, towers, currencies, and new systems.

## Key Features

- Button-based progression with upgrades, towers, conversion, and ascension
- Aura rolling and other RNG-based rewards
- Arcade challenges, awards, music, and unlockable features
- New Game+ for harder progression and additional content
- The **Cerulean Void**, an alternate realm with Void Fishing, rods, fish mutations, scales, biomes, and day/night cycles
